# Kesavan Portfolio

React + TypeScript + Vite portfolio.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Resume

Add your resume as:

```text
public/resume.pdf
```

The download button is already configured.

## Deploy to Vercel

1. Create a GitHub repository.
2. Push this project.
3. Import the repository into Vercel.
4. Use the default Vite settings.
5. Deploy.
